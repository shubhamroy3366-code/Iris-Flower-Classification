# Iris Flower Classification

This is a Machine Learning project
that predicts Iris flower species.

## Technologies
- Python
- Scikit-learn
- Machine Learning

## Features
- Train ML model
- Save trained model
- Predict flower species

## How to Run

1. Install requirements:
   pip install -r requirements.txt

2. Train model:
   python train_model.py

3. Run application:
   python app.py
